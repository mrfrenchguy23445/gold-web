# Gold UI

The design system for Gold-Web: colour tokens, type, spacing and shared
components, in a form the front end can consume.

The rules are in `docs/DESIGN.md`; this directory will hold the implementation
of them — a tokens file (`tokens.css` or similar) and, later, shared components.
Nothing is here yet.

The accent is gold (`#e0b84c`) on pure black (`#000000`), used sparingly.
